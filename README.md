# Agentic AI in Azure - Udemy

Code for the Udemy course.

| Project | What it is |
| --- | --- |
| [Annual Report RAG using Azure Services](./Annual%20Report%20RAG%20using%20Azure%20Services) | Year-over-year questions on annual reports with Azure OpenAI, AI Search, Blob Storage and PyMuPDF4LLM, plus guardrails, human review and a web UI |
| [Azure Graph RAG on DBs](./Azure-Graph-RAG-on-DBs) | Plain-English questions over a 20-table mutual fund database: the schema as a graph (Apache AGE) with tables as nodes and joins as hops, pgvector retrieval, a LangGraph agent that writes checked read-only SQL, Azure OpenAI, Content Safety, Application Insights, App Service and Entra ID sign-in, plus a web UI that shows every step |
