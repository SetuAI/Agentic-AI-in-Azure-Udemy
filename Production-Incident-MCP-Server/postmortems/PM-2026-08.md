
# PM-2026-08 · Loan status page slow after the loans table grew

- Date: 2026-08-19
- Services: loan-service, api-gateway
- Severity: SEV-3
- Duration: 2 days

## Summary

GET /loans/status became slow during the day, with p95 time rising from 200 ms to over 4 seconds.

## Impact

No errors, but customers waited several seconds to see their loan status, and support calls increased.

## Root cause

The loans table had grown past 20 million rows, and the status lookup had no database index on the customer number, so every lookup read far more rows than needed.

## What fixed it

Adding an index on the customer number column. The p95 time dropped back to about 180 ms.

## Lessons and follow-ups

- Track p95 time per endpoint, not only error counts. Slowness without errors is still an incident.
- Review slow database queries every month.
