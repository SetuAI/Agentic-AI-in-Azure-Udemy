
# PM-2025-12 · Some customers debited twice by the EMI auto-debit job

- Date: 2025-12-02
- Services: payments
- Severity: SEV-1
- Duration: 1 night

## Summary

About 140 customers had their EMI collected twice by the nightly auto-debit job.

## Impact

140 customers were charged twice. All were refunded within 24 hours.

## Root cause

The bank gateway was slow that night. Payments retried debits that had in fact already succeeded, because it did not check whether the first attempt had gone through before retrying.

## What fixed it

Refunds for every double debit, and a code fix: each debit now carries a unique reference, so the bank refuses a second debit with the same reference.

## Lessons and follow-ups

- Every money-moving request must be safe to retry (idempotent).
- Added a nightly check that compares debits with loan schedules and flags duplicates.
